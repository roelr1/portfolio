# Portfolio

Portfolio-website van zelfgebouwde tools. Gebouwd met Jekyll en gratis gehost via GitHub Pages.

## Site bewerken

- Elke tool is een Markdown-bestand in de map `tools/`. Kopieer `_template.md`, vul het in, en voeg op `index.md` een korte vermelding toe.
- GitHub bouwt de site automatisch bij elke wijziging op de branch `main`.

## Eenmalige activering van GitHub Pages

1. Ga in deze repository naar Settings → Pages.
2. Kies bij Branch: `main` en map `/ (root)`, en klik op Save.
3. Na enkele minuten staat de site live op: https://roelr1.github.io/portfolio/

## Lokaal werken (optioneel)

```bash
git clone https://github.com/roelr1/portfolio.git
cd portfolio
```

Je kunt de Markdown-bestanden in elke editor aanpassen en met `git add`, `git commit` en `git push` publiceren. Lokaal een Jekyll-preview draaien is mogelijk maar niet nodig.
